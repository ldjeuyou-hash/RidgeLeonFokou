# Fonction permettant de prédire les valeurs de la variable réponse pour un objet de classe ridge

Fonction permettant de prédire les valeurs de la variable réponse pour
un objet de classe ridge

## Usage

``` r
# S3 method for class 'ridge'
predict(object, dt = object$X, ...)
```

## Arguments

- object:

  un objet de classe ridge

- dt:

  les données pour lesquelles faire des prédictions

- ...:

  paramètres supplémentaires pour la fonction predict
