# Variable finale a calculer

Variable finale a générer en utilisant la regression ridge.

## Usage

``` r
Y
```

## Format

Un data frame contenant 1000 observations :

- Y:

  Variable réponse numérique genere par par 4.5 \* X1 + 2.7 \* X2 +
  sin(X3)+ 0.7 \* X4

## Source

Données Calculées à partir de la matrice "X" et des coefficients 4.5,
2.7, sin et 0.7.
